# Quality Review Framework

## Why human review matters

AI can help generate learning materials, but generated content should not automatically be considered accurate or ready for learners.

I included a quality review tracker in this prototype to make human oversight part of the process.

## Review criteria

The tracker uses five main checks:

| Criterion | What it checks |
|---|---|
| Factual accuracy | Does the content reflect the original source correctly? |
| Objective alignment | Does the material support the stated learning objectives? |
| Clarity | Is the language easy to understand? |
| Accessibility | Is the content presented in a way that is accessible to the intended audience? |
| Source grounding | Can the generated content be traced back to the supplied material? |

## Review process

1. AI generates the learning package.
2. The output is saved in the Generated Content sheet.
3. A human reviewer assesses the content using the review criteria.
4. Scores and comments are recorded in the Quality Review sheet.
5. The reviewer records a decision before the content is considered for use.

## Example review

For the demonstration, I reviewed sample content about protecting customer information.

The sample review included scores, reviewer comments and a decision of "Approved for demo only".

This does not mean the content has been approved for use in a real organisation.

## Future improvements

If I develop the prototype further, I would like to introduce:

- More structured factual verification.
- Clearer source references for individual learning points.
- Accessibility checks for different learner needs.
- A defined approval process involving subject-matter experts.
- Learner feedback to evaluate whether the materials are useful.

## Important limitation

This framework is an initial quality-control approach. It has not been validated in a live organisational learning environment.
