# AI Prompt – Learning Content Generation

## Purpose

The prompt instructs the AI to act as an instructional designer and transform existing training material into structured learning resources.

The goal is not simply to summarise the source, but to create content that can support employee learning.

## Prompt used

```text
Act as an experienced instructional designer.

Your task is to transform the training source material provided into a clear, engaging and structured learning package.

Use only the information provided in the source material. Do not invent facts, policies or procedures.

Create the following:

1. MICRO-LEARNING LESSON
- A clear title.
- Learning objectives.
- A short introduction.
- Key learning points.
- Practical examples where supported by the source.
- A short summary of the main takeaways.

2. KNOWLEDGE-CHECK QUIZ
- Create five questions based on the source material.
- Include answer options.
- Identify the correct answer.
- Provide a short explanation for each answer.

3. FACILITATOR GUIDE
- Explain how a facilitator can introduce the topic.
- Include suggested discussion points.
- Provide questions to encourage participation.
- Include a short closing summary.

Keep the language clear, accessible and appropriate
for the intended learner audience.

Make sure the learning objectives align with the
generated content.

Clearly identify any information that is missing
or requires human verification.

Source material:
[Insert training source]

Intended audience:
[Insert learner audience]

Topic:
[Insert training topic]
```

## Responsible AI considerations

The prompt is designed to encourage source-grounded content generation. However, generated material still requires human review.

The prototype includes a separate quality review process to assess factual accuracy, clarity, accessibility and alignment with learning objectives.

**Note:** This is a documented version of the prompt approach used in the prototype, not a verbatim export of the original Make.com prompt.
